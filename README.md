# 大肥鱼 Bot 控制台

在 DeepSeek Harness（DSH）中管理 Windows 本地 QQ 机器人：查看服务与登录状态、扫码登录，
调整记忆、语音概率和回复节奏。机器人由 AstrBot 与 NapCat 配合运行。

**当前发布的是源码预览版，不能通过下载本仓库 ZIP 一键完成安装。**
本仓库包含控制台、重启插件、部分部署工具和 AstrBot 配套补丁。
完整安装包仍在干净 Windows 虚拟机中验收，尚未提供公开下载。

## 当前功能

- 本机QQ状态及扫码入口、明确的账号受限提示。
- 私聊语音回复概率、分条开关、首条/段间等待、最多文字条数。
- 文字先发语音随后；新增配置字段已在AstrBot默认配置登记。
- 运行库补丁有版本/摘要校验、备份与回退，不覆盖账号、记忆及自定义配置。

配套版本：Windows x64、DSH 0.2.1-rc.3、AstrBot 4.29.3、Python 3.12。
Windows 10 测试环境中的文字、语音、记忆检索和主动消息已有实际验证；
v7 完整包的干净系统首装、重启后保留及长期运行仍待验收。
自动检查 GitHub 更新和一键升级尚未实现。

## 目录

| 路径 | 内容 |
| --- | --- |
| `plugins/dsh-dafeiyu-console` | 控制台界面、本机 HTTP 接口与进程管理 |
| `plugins/dsh-restart-app` | DSH 重启入口 |
| `deployment` | 部署脚本、依赖版本锁与本地向量服务源码 |
| `runtime-patches/astrbot-4.29.3` | revision 4 补丁、修改源码、校验和回退工具 |
| `LICENSES` | 随附第三方许可 |

本仓库没有根 `package.json`，不能把仓库 URL 直接作为控制台插件的安装地址。
部署脚本按照完整发行包的目录布局编写；本仓库不含所需的全部发行文件。
使用边界见 [开发与安装说明](docs/开发与安装说明.md)。

## 本地检查

安装 Node.js 后，在仓库根目录运行：

```sh
node plugins/dsh-dafeiyu-console/scripts/smoke.mjs
```

仅使用内存假文件/假进程/假网络；不会启动机器人或发送消息。
