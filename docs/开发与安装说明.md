# 开发与安装说明

本仓库是源码预览，尚未包含可以从零构建完整安装包的全部文件。请勿把 `deployment/安装.bat`
单独当成完整安装器运行：它依赖随包 Python、wheelhouse、模型、配置模板及其它工具。
`deployment/connect_dsh.py` 也要求完整发行包布局，不应从本源码目录直接运行。
后续通过新机验收并确认分发条件后，再补充正式获取和安装入口。

## 审阅代码

界面入口是 `plugins/dsh-dafeiyu-console/client.js`，本机 API 入口是同目录 `index.js`。
宿主与前端需 DSH 提供的插件运行环境，普通浏览器无法直接运行这些组件。
该插件目录的 `cordis.patch.yml` 是空凭证模板；部署后含本机密码的副本不得提交回来。
请始终在独立运行目录中安装，不把正在使用的机器人目录或 `.dsh` 用户目录加入 Git。

## 冒烟检查

```sh
node plugins/dsh-dafeiyu-console/scripts/smoke.mjs
```

该检查使用内存模拟，不安装依赖、不拉起 QQ、不发消息。它不能代替 Windows 端到端验收。

## AstrBot 补丁

补丁限定 AstrBot 4.29.3、Python 3.12 和既有完整包的 venv 结构。
`manifest.json` 记录原版、已知旧补丁和本版源码的摘要；未知修改会被拒绝覆盖。
审阅 `apply_voice_order.py --help` 后，只在已备份的测试安装中使用。
应用源码后需要重启 AstrBot 才加载；不要为补丁测试反复重启 QQ。
保留安装时生成的原版备份，按工具提供的恢复模式回退。

## 安装包使用提醒

完整包需要全部解压后，再从解压目录运行入口，不能在压缩软件里直接双击安装脚本。
当前新机安装正在验收；发现问题请在 Issue 中提供系统版本、操作步骤和脱敏报错。
不要上传 Key、密码、token、cookie、登录二维码或含用户聊天的日志。
